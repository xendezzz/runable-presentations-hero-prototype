# Presentation assets

Original fictional presentation examples created for this page. Hero decks each contain a cover, an explanatory slide, and an actionable closing slide. Numerical examples, if present, are illustrative rather than factual claims.

## Pinterest inspiration reviewed

- [Minimal pitch deck](https://in.pinterest.com/pin/211174979103000/): hierarchy, restrained color, distinct slide types.
- [Editorial presentation](https://in.pinterest.com/pin/703756189588908/): asymmetric image placement and editorial typography.
- [Report charts](https://in.pinterest.com/pin/78531587248991208/): informative chart titles and compact data layouts.
- [Annual report](https://in.pinterest.com/pin/48976714692752062/): coherent systems across varied layouts.

These were viewed for design principles, not copied or downloaded. All artwork was newly generated without earlier page images as references.

## Files

- `presentation-final-prompts.json`: exact final generation prompts.
- `presentation-assets.json`: source and optimized output mapping.
- `dist/assets/presentations/`: optimized WebP artwork and three SVG viewports per hero deck.

The second section is a static workflow illustration. Feature panels and device screens are illustrative images, not functional editors. The surrounding page interactions remain live.
